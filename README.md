# NoriNori Drill support site

このリポジトリは「ノリノリドリル」専用のサポートサイトです。

- Bundle ID: `com.shirai.abcfever`(旧名 ABCフィーバーのまま)
- 公開先: `https://shirai-aka.github.io/norinori-drill-support/`
- 他アプリのページをこのリポジトリへ配置・公開しないでください。

公開前に次の検査を実行します。

```sh
sh scripts/validate_site.sh
```

検査は3ページすべてに正しいアプリ名があり、別アプリ名が混入していないこと、
プライバシーポリシーにキッズ向けの方針(広告なし・通信なし・保護者ゲート・ATT)が記載されていることを確認します。
